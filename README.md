
# PIXERA RenderBridge

This parent repo is for AVStumpfl PIXERA's RenderBridge.

For more information on RenderBridge [refer to our documentation on it](https://help.pixera.one/en_US/renderbridge-extension-mechanism).

## Writing Extensions

To get started with writing extensions for PIXERA's RenderBridge, clone the [RenderBridge SDK](https://github.com/avstumpfl/render-bridge-sdk) and follow the build instructions.
